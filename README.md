# WIKA CPG1500 Graph Processor

Автоматизированный локальный инструмент на Python 3.11+ под Windows для обработки, очистки, статистического анализа и визиуализации CSV-файлов, экспортированных из цифрового манометра **WIKA CPG1500**.

---

## ⚠️ ВАЖНЫЕ ПРИМЕЧАНИЯ И ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ

1. **Сохранность исходных данных**: Программа **НИКОГДА не изменяет** исходные CSV-файлы. Все вычисления производятся над копией данных в оперативной памяти, а результаты сохраняются в папку `output/`.
2. **Технологическая документация**: Программа не заменяет требования государственных стандартов, отраслевых норм и технологических регламентов испытаний.
3. **Критерии PASS / FAIL**: Результат соответствия (PASS / FAIL) вычисляется **исключительно** на основе численных критериев и допусков, заданных пользователем в файле `config.json`. Если параметры испытания не заданы, автоматическая инженерная оценка не производится (выводится статус *"Не оценивалось"*).

---

## 🚀 БЫСТРЫЙ СТАРТ ДЛЯ ПОЛЬЗОВАТЕЛЯ

Для работы с программой не требуются навыки программирования. Выполните три простых шага:

1. **Скопируйте** один или несколько CSV-файлов WIKA CPG1500 в папку `input`.
2. **Дважды щёлкните** мышью по файлу **`START.bat`**.
3. После завершения обработки автоматически откроется папка **`output`**, в которой будут расположены:
   - **`output/graphs/`** — графики давления в формате PNG;
   - **`output/excel/`** — отчёты Excel (.xlsx) с исходными, очищенными данными, статистикой и встроенным графиком;
   - **`output/reports/`** — краткие текстовые отчёты (.txt);
   - **`output/logs/`** — журналы работы программы.

## 🛠️ ПЕРВОНАЧАЛЬНАЯ УСТАНОВКА

Если вы запускаете программу впервые на новом компьютере с Windows 10 или 11:

### Шаг 1. Проверьте наличие Python
- Скачайте и установите **Python 3.11** или выше с официального сайта [python.org](https://www.python.org/downloads/).
- ⚠️ **Обязательно выберите галочку "Add Python to PATH"** в первом окне инсталлятора.

### Шаг 2. Запустите установку компонентов
- Дважды щёлкните по файлу **`INSTALL.bat`**.
- Скрипт автоматически создаст изолированное виртуальное окружение `.venv` и установит все необходимые зависимости (`pandas`, `matplotlib`, `openpyxl`, `charset-normalizer`, `pytest`).
- *Примечание*: Если вы сразу запустите `START.bat`, он сам автоматически вызовет `INSTALL.bat`, если виртуальное окружение ещё не создано.

## ⚙️ НАСТРОЙКА ПАРАМЕТРОВ (config.json)

Все параметры программы настраиваются в файле `config.json` в корневой папке проекта. 

### Пример файла `config.json`:
```json
{
  "target_unit": "bar",
  "default_input_unit": null,
  "move_processed_files": false,
  "open_output_folder_after_finish": true,
  "graph": {
    "dpi": 180,
    "width_inches": 14,
    "height_inches": 7,
    "show_minimum": true,
    "show_maximum": true,
    "show_limits": true,
    "show_hold_period": true
  },
  "analysis": {
    "test_pressure_bar": 20.0,
    "lower_limit_bar": 18.0,
    "upper_limit_bar": 22.0,
    "hold_start_time_minutes": 1.0,
    "hold_end_time_minutes": 10.0,
    "allowed_drop_bar": 0.5,
    "create_pass_fail_result": true
  }
}
```

### Подробное описание всех параметров:

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `target_unit` | строка | Целевая единица измерения давления на графиках и в отчётах. Всегда `"bar"`. |
| `default_input_unit` | строка / null | Единица измерения исходных данных по умолчанию (например, `"bar"`, `"psi"`, `"kPa"`), если она отсутствует в заголовке CSV. По умолчанию `null`. |
| `move_processed_files` | boolean | `true` — перемещать обработанные CSV из `input/` в `processed/`; `false` — копировать в `processed/` и оставлять исходные файлы в `input/`. |
| `open_output_folder_after_finish` | boolean | `true` — автоматически открывать проводник Windows с папкой `output/` по окончании работы. |
| `graph.dpi` | число | Разрешение сохраняемого PNG-графика (точек на дюйм). По умолчанию `180`. |
| `graph.width_inches` / `height_inches` | число | Ширина и высота графика в дюймах (соотношение 14×7 обеспечивает формат 16:9). |
| `graph.show_minimum` / `show_maximum` | boolean | Показывать ли на графике отметки с точными значениями минимума и максимума. |
| `graph.show_limits` | boolean | Показывать ли на графике пунктирные горизонтальные линии нижнего и верхнего лимитов. |
| `graph.show_hold_period` | boolean | Выделять ли полупрозрачным фоном участок выдержки высокого давления. |
| `analysis.test_pressure_bar` | число / null | Номинальное испытательное давление в bar. |
| `analysis.lower_limit_bar` | число / null | Нижняя допустимая граница давления на участке выдержки (bar). |
| `analysis.upper_limit_bar` | число / null | Верхняя допустимая граница давления на участке выдержки (bar). |
| `analysis.hold_start_time_minutes` | число / null | Время начала участка выдержки (в минутах от начала теста). |
| `analysis.hold_end_time_minutes` | число / null | Время окончания участка выдержки (в минутах от начала теста). |
| `analysis.allowed_drop_bar` | число / null | Максимально допустимое падение давления за период выдержки (bar). |
| `analysis.create_pass_fail_result` | boolean | `true` — рассчитывать статус PASS/FAIL по заданным лимитам; `false` — выводить *"Не оценивалось"*. |

## ❓ ЧТО ДЕЛАТЬ ПРИ ВОЗНИКНОВЕНИИ ПРОБЛЕМ

### 1. Если единица измерения давления не определилась
Если при запуске файл попал в папку `failed/`, а в текстовом отчёте написано, что единица не найдена:
- Откройте `config.json` в Блокноте.
- Укажите единицу измерения прибора в параметре `"default_input_unit": "bar"` (или `"psi"`, `"kPa"`, `"MPa"` и т.д.).
- Верните CSV-файл из папки `failed/` обратно в `input/` и снова запустите `START.bat`.

### 2. Если столбцы времени или давления не найдены
- Откройте файл ошибки `.error.txt` в папке `failed/`. В нём будут перечислены все заголовки столбцов, которые были найдены в вашем файле.
- Убедитесь, что заголовок времени содержит одно из стандартных слов (`Timestamp`, `Time`, `Date`, `Zeit`, `Время`, `Aika`) или столбец давления содержит (`Pressure`, `Messwert`, `Druck`, `Paine`, `Давление`, `bar`, `psi`).

### 3. Как отправить разработчику лог ошибки
Если произошёл неожиданный сбой:
1. Зайдите в папку `output/logs/` и найдите файл `app.log`.
2. Зайдите в папку `failed/` и найдите файл `[Имя_файла].error.txt`.
3. Отправьте эти файлы системному администратору или разработчику для быстрого устранения проблемы.

## 🖥️ КОМАНДНАЯ СТРОКА (PYTHON CLI)

Для опытных пользователей и интеграции в автоматизированные сценарии поддерживается запуск через CLI:

```bash
# Обычный запуск по умолчанию
python -m wika_report

# Указание кастомных папок ввода и вывода
python -m wika_report --input "C:\Test\CSV" --output "C:\Test\Results"

# Указание отдельного конфигурационного файла
python -m wika_report --config my_config.json

# Обработка только одного конкретного файла
python -m wika_report --file "input\Log 1.csv"

# Пробный запуск (dry-run) без сохранения файлов
python -m wika_report --dry-run
```

## 🧪 ТЕСТИРОВАНИЕ И ПРОВЕРКА КАЧЕСТВА

Проект покрыт автоматическими тестами `pytest`:

```bash
.venv\Scripts\pytest
```

Тесты проверяют:
- определение разделителей (`;`, `,`, `\t`) и кодировок (`UTF-8`, `Windows-1251`);
- чтение десятичных запятых и точек;
- многоязычный поиск столбцов и конвертацию единиц давления;
- полный сквозной smoke-тест генерации PNG, XLSX, TXT и журналов работы.
