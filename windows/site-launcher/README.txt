ARDOR Pressure Test — Windows launcher
======================================

Назначение
----------
Создаёт переносимый файл "ARDOR Pressure Test.exe" или полноценный установщик.
При запуске приложение
открывает https://84-247-130-242.sslip.io в отдельном окне Microsoft Edge
или Google Chrome. Если ни один из них не найден, используется браузер Windows
по умолчанию.

Сборка
------
Переносимый EXE:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\BUILD_SITE_APP.ps1

Готовый файл появится здесь:

   dist\ARDOR Pressure Test.exe

Установщик (рекомендуется для передачи другим сотрудникам):

1. Установите Inno Setup 6 с https://jrsoftware.org/isdl.php
2. Выполните:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\BUILD_INSTALLER.ps1

3. Готовый установщик появится здесь:

   release\ARDOR-Pressure-Test-Setup.exe

Использование и передача
------------------------
Установщик создаёт ярлык с ARDOR-иконкой на рабочем столе и запись удаления
программы в Windows. Для отправки через WhatsApp рекомендуется сначала
поместить установщик в ZIP — мессенджеры часто блокируют голые EXE-файлы.

Переносимый EXE также можно переместить на рабочий стол.
Получателю нужен Windows, подключение к интернету и современный браузер.
Пароли, cookies, токены и производственные данные в EXE не включаются.

Microsoft SmartScreen может показать предупреждение для неподписанного
внутреннего EXE. Это ожидаемо: файл не подписан коммерческим сертификатом.
