## Живой предпросмотр (3-я итерация)

В режиме «Редактировать» PDF рядом с формой перерисовывается по мере ввода (пауза ~0,7 с после последнего
изменения): `POST /api/v1/records/{id}/preview-pdf?kind=full|official` строит PDF из несохранённых значений
формы и ничего не пишет в БД. В полном предпросмотре нет таблиц измерений (они не зависят от формы и занимают
большую часть времени построения). Заголовок `X-PTR-Log-Pages` даёт страницу приложения каждого лога —
просмотрщик открывает страницу, которую сейчас правят (бланк → стр. 1, поле лога → его приложение).
Сохранение — только кнопкой «Сохранить». Тест: `test_live_preview_uses_unsaved_values_and_writes_nothing`.
